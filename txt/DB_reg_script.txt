คุณคือผู้เชี่ยวชาญการเขียน Google Apps Script ระดับมืออาชีพ
ช่วยเขียน Google Apps Script สำหรับจัดการระบบลงทะเบียนสมาชิกในกลุ่ม LINE (Group/Room) ผ่าน LINE Messaging API โดยทำงานร่วมกับ Google Sheets ชื่อชีทว่า "Data"

### 🎯 โครงสร้างตาราง Google Sheets (ชีท "Data")
เรียงลำดับคอลัมน์จากซ้ายไปขวา (แถวที่ 1 เป็น Header):
- Column A (1): groupid (รหัสกลุ่ม/ห้อง)
- Column B (2): userid (รหัสผู้ใช้)
- Column C (3): display (ชื่อดิสเพลย์ LINE)
- Column D (4): name (ชื่อ-นามสกุล จริงที่ลงทะเบียน)
- Column E (5): room (ชื่อกลุ่ม/ชื่อห้อง)

---

### 🛠️ ฟังก์ชันและการตอบสนองต่อ Event (Webhook)

1. **การบันทึกข้อมูลและอัปเดต (Upsert Function):**
   - ทุกครั้งที่มีการบันทึกข้อมูล ต้องอัปเดตทั้ง groupId, userId, display, name และ room (ชื่อห้อง) ให้ครบถ้วนเสมอ
   - หากเคยมีข้อมูล groupId + userId นั้นในชีทแล้ว ให้ทำการอัปเดตชื่อ/ดิสเพลย์/ชื่อห้อง
   - หากยังไม่มี ให้บันทึกเพิ่มเป็นแถวใหม่ (appendRow)

2. **เหตุการณ์สมาชิกใหม่เข้ากลุ่ม (`memberJoined`):**
   - ดึงโปรไฟล์สมาชิก ดึงชื่อกลุ่ม และบันทึกข้อมูลลงชีท (คอลัมน์ name ให้ปล่อยว่าง)
   - ส่ง Flex Message ยินดีต้อนรับสมาชิกใหม่ พร้อมอธิบายวิธีลงทะเบียนเบื้องต้น

3. **เหตุการณ์สมาชิกลากิจ/ออกจากกลุ่ม (`memberLeft`):**
   - ลบแถว (Delete Row) ของสมาชิกคนนั้นในกลุ่มนั้นออกจากชีททันที

4. **การคำนวณธีมสีตามชื่อกลุ่ม (Dynamic Theme Colors):**
   - ให้คำนวณหาร 4 จากความยาวชื่อกลุ่ม เพื่อกำหนดสีหลัก (main), สีพื้นหลังแถว (bg), และสีข้อความ (text) แบบสลับ 4 โทนสี (น้ำเงิน, เขียว, ชมพู, ม่วง)

---

### 💬 คำสั่งข้อความ (Message Commands)

1. `*## [ชื่อ-นามสกุล]` -> **ลงทะเบียน / แก้ไขชื่อ**
   - ตัดคำว่า *## ออก นำชื่อ-นามสกุลมาบันทึก/อัปเดตลงคอลัมน์ `name` พร้อมอัปเดตคอลัมน์ `room` และส่งข้อความยืนยันสำเร็จ

2. `%%` -> **สละสิทธิ์**
   - ให้ทำการ **"ลบแถว (Delete Row)"** ของสมาชิกคนนั้นออกทั้งบรรทัด (เหมือนสมาชิกออกจากห้อง) แล้วส่งข้อความตอบกลับยืนยัน

3. `*#` -> **ดูรายชื่อผู้ลงทะเบียนแล้ว (Flex Carousel)**
   - ดึงเฉพาะคนที่กรอกชื่อ `name` แล้ว แสดงผลเป็น Flex Message Carousel (หน้าละ 10 คน)
   - แถวรายการให้มีลำดับ, ชื่อลงทะเบียน, และดิสเพลย์ LINE
   - มีการใส่สีพื้นหลังสลับแถวคู่/คี่ตามธีมสีของกลุ่ม

4. `$$` -> **ตรวจสอบสมาชิกทั้งหมดในห้อง (Admin Check Flex Carousel)**
   - ดึงสมาชิกทุกคนในกลุ่มนั้นขึ้นมาแสดง (หน้าละ 10 คน)
   - แสดงผล **`display`** คู่กับ **`name`**
   - **กรณีคนที่ยังไม่ได้ลงทะเบียน:** ในช่อง `name` ให้ปล่อยเป็นค่าว่างไว้ (`''`) เพื่อให้ Admin ตรวจสอบได้ง่ายว่าใครยังไม่ลงทะเบียน

5. `&&` -> **สรุปรายชื่อแบบ Text ธรรมดา**
   - ดึงรายชื่อเฉพาะคนที่ลงทะเบียนแล้ว ออกมาเป็นข้อความ Text เรียงลำดับ 1, 2, 3... เพื่อให้ Admin คัดลอกง่าย

6. `#exam` -> **คู่มือแนะนำการใช้งาน**
   - ส่ง Flex Message คู่มือตัวอักษรใหญ่พิเศษ แสดงตัวอย่างการใช้งานคำสั่ง *##, *#, %%

### 🚪 ฟังก์ชันเสริมสำหรับ Admin (เมนูบาร์ Google Sheet & Control)

1. **เมนูลัดบน Google Sheet (`onOpen`):**
   - สร้าง custom menu บน Google Sheet ชื่อ "🤖 ระบบจัดการ บอท LINE"
   - เมนูย่อย 1: "🚪 สั่งบอทออกจากกลุ่ม (Pop-up)"
   - เมนูย่อย 2: "✉️ บอทส่งลิงก์เชิญเข้ากลุ่มหาผู้ใช้ (Pop-up)"

2. **Pop-up สั่งเตะบอทออกจากกลุ่ม (`promptLeaveGroup`):**
   - เด้ง UI Prompt ให้ Admin กรอก `groupId` แล้วยิง API สั่งให้บอทออกจากกลุ่มนั้นๆ จากระยะไกล

3. **Pop-up บอทส่งลิงก์เชิญส่วนตัว (`promptSendInviteLink`):**
   - เด้ง UI Prompt รับ `targetUserId` และ `groupInviteUrl` แล้วยิง Flex Push Message ส่งลิงก์เชิญเข้ากลุ่มไปหาผู้ใช้นั้นในแชทส่วนตัว

---

### ⚙️ ข้อกำหนดด้านเทคนิค
- กำหนดตัวแปร `LINE_ACCESS_TOKEN` ไว้ด้านบนสุด
- การลบแถวใน Google Sheet ให้ใช้วิธีวนลูปถอยหลัง (จากล่างขึ้นบน) เพื่อป้องกัน Index คลาดเคลื่อน
- โค้ดทั้งหมดต้องรวมอยู่ในไฟล์เดียวกัน พร้อมใช้งานทันที รัดกุม มีการใส่ try-catch จัดการ Error อย่างเหมาะสม
